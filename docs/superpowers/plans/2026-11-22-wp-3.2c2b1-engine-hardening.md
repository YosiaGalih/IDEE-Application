# WP-3.2c2b1: pengerasan engine (rencana implementasi)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Engine harus siap sebelum langkah LLM pertama dipasang. Yang dikerjakan:
- kontrak hasil langkah yang lengkap: `interrupt`, `StepAbandoned`, allowlist;
- owner lease per delivery;
- tulisan engine yang berbatas waktu;
- margin heartbeat yang nyata, plus lease guard;
- batas durasi per delivery;
- dispatch sesuai kapasitas;
- guard penulis `agent_runs` yang menutup celah sisa.

**Architecture:** Hampir semua perubahan ada di `app/workflow/engine.py`, `lease.py`, `dispatch.py`, dan `states.py` (`check_error_code`). Ditambah `app/worker/identity.py` (`delivery_owner`), `jobs.py`, `celery_app.py` (cek batas delivery), dan `core/config.py` (`task_delivery_max_minutes`). Satu baris env masuk `infra/compose.yml`.

**Tech Stack:** Python 3.12 asyncio, SQLAlchemy async + asyncpg, PostgreSQL 16, Celery 5.

**Spec:** `docs/superpowers/specs/2026-11-17-wp-3.2-workflow-engine-design.md` §16.4 (Keputusan #73–#81), §16.5 (rancangan rinci), dan §16.5a (builder check). §16.5a mengikat bila berbeda dengan §16.5.

## Global Constraints

- **Lapisan import.** `app.workflow` tidak mengimpor `app.services`/`app.worker`, dan `uv run lint-imports` harus bersih.
- **Penulisan status.** Status hanya lewat `transition()`/`fail_task()` di `states.py`. Checkpoint hanya per kunci (`app/workflow/checkpoint.py`).
- **Log.** Isinya id dan tipe galat saja. Tidak boleh ada `exc_info`, teks pesan, maupun owner atau token.
- **Kode hasil langkah.** `error_code` dan `reason` dari langkah mengikuti `[a-z][a-z0-9_]{0,63}` lewat `check_error_code`.
- **Konstanta:**
  - `ENGINE_WRITE_TIMEOUT_S = 15`
  - `LEASE_SAFETY_SECONDS = 10` (bawaan `WorkflowPorts.lease_safety_s`)
  - `DELIVERY_MARGIN_SECONDS = 600`
  - `TASK_DELIVERY_MAX_MINUTES` bawaan 60
  - `LEASE_OWNER_LENGTH = 120`
- **Kode error task baru:** `step_result_invalid` dan `duration_exceeded`.
- **Nilai `Stopped` baru:** `interrupted`, `abandoned`, `step_result_invalid`, `duration_exceeded`.
- **Test:**

## Review Focus

1. **Tenggat delivery.**
   - Langkah dibatalkan sekali.
   - Heartbeat hidup selama pembersihan.
   - Status jujur ditulis sesudahnya, atau tidak ada tulisan bila lease hilang.
   - Test di Task 5.
2. **Margin heartbeat.** PoC black hole: sisa lease saat langkah dibatalkan ≥ 1,0 dtk (lease 6 dtk / beat 1 dtk / safety 3,5 dtk). Test di Task 4.
3. **Owner per delivery.** Dua delivery di satu proses tidak saling memperpanjang lease, dan hostname 120 karakter tidak menyebabkan `ValueError`. Test di Task 2.
4. **Allowlist.**
   - `transition(COMPLETED)` dan `interrupt` dari `draft` menjadi `failed step_result_invalid` tanpa raise.
   - `interrupt` dari `running` tidak masuk `completed_steps`.
   - Test di Task 1.
5. **Lock timeout claim → `BUSY`.** Tulisan macet dibatasi `ENGINE_WRITE_TIMEOUT_S` (+±2 dtk penutupan). Test di Task 3.

### Task 4: Margin heartbeat, lease guard, regresi black hole

**Files:**
- Modify: `backend/app/workflow/engine.py`, `backend/app/workflow/lease.py` (`LEASE_SAFETY_SECONDS`)
- Test: `backend/tests/integration/test_engine.py`; baru `backend/tests/integration/test_engine_blackhole.py` ditambah helper proxy (mis. `backend/tests/blackhole_proxy.py`)

**Interfaces:**
- **Port dan invarian.** `WorkflowPorts.lease_safety_s: float = LEASE_SAFETY_SECONDS`. Invarian dicek di `TaskEngine.__init__`: `heartbeat_s > 0`, `lease_safety_s > 0`, `heartbeat_s + lease_safety_s < lease_duration().total_seconds()`.
- **Aritmetika heartbeat** (§16.5a #5):
  - `H = last_ok + lease − safety`;
  - tidur `min(beat, max(0, H − now))`;
  - setiap percobaan `asyncio.timeout_at(min(attempt + beat, H, attempt + ENGINE_WRITE_TIMEOUT_S))`;
  - menyerah bila `monotonic ≥ H` atau bila timeout yang berbunyi adalah H;
  - di awal loop, `H − now ≤ 0` → `lease_heartbeat_gave_up` + `LeaseLost`.
- **Lease guard.** `LeaseGuard(task_id, owner)` frozen, dengan `owner` `repr=False`. `async hold(db)` memanggil `renew_lease` dan melempar `LeaseLost`. `StepContext.lease: LeaseGuard` ditambahkan sebagai field kelima. Docstring memuat empat aturan dari §16.5a #8.
- **Nilai test.** `make_engine` mendapat `lease_safety_s`:
  - lease 2 dtk / beat 0,2 → safety 0,5;
  - lease 1 / beat 0,1 → 0,3;
  - lease 1 / beat 0,5 → 0,2.

- [ ] **Step 1: Failing tests:**
  - invarian ditolak saat engine dibuat;
  - `test_heartbeat_give_up_is_logged` tetap tanpa baris `lease_heartbeat_failed`;
  - guard: `hold` memperpanjang lease di transaksi pemanggil, dan melempar `LeaseLost` bila owner salah atau lease mati;
  - repr guard tidak memuat owner;
  - black hole (dari `scratchpad/ag13poc-3.2c1/test_poc_heartbeat_blackhole.py`, varian `pool_pre_ping` dan tanpa): lease 6 dtk, beat 1 dtk, safety 3,5 dtk, sisa lease saat langkah dibatalkan ≥ 1,0 dtk;
  - flow proxy dilepas sebelum `dispose()`.
- [ ] **Step 2: Run.** FAIL.
