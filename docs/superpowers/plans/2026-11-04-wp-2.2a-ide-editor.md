# WP-2.2a IDE Explorer + Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Layar `/projects/:projectId/workspace`: explorer, editor Monaco multi-tab dengan simpan berversi dan dialog konflik, file biner/besar sebagai metadata, panel cari, serta panel chat/terminal yang berstatus "belum tersedia".

**Architecture:**
- Klien dan hook di `src/api/workspace.ts` dan `src/api/hooks/useWorkspace.ts`, dengan Zod untuk tree, file, git status, dan search.
- Layar di `src/features/workspace/`. State tab (`useEditorTabs`) adalah reducer murni, sehingga aturan simpan dan konflik bisa dites tanpa Monaco.
- `CodeEditor.tsx` adalah satu-satunya file yang mengimpor `monaco-editor`. Layar dimuat lazy dari `routes.tsx`.

**Tech Stack:** React 19, TanStack Query 5, Zod, `monaco-editor` (ESM, dipin persis), Vitest + RTL + MSW, dan Playwright untuk live check.

**Spec:** `docs/superpowers/specs/2026-11-04-wp-2.2-ide-design.md` (konflik #71).

## Global Constraints

- Paket baru di-resolve dengan `npx npm@11.21.0 install --before=2026-10-10 --save-exact monaco-editor` (tanggal `exclude-newer` backend). Tanpa `@monaco-editor/react` dan tanpa CDN.
- Opsi Monaco: `links: false`, `readOnly` bila tidak punya `workspace:write`. Worker lewat `monaco-editor/esm/vs/editor/editor.worker?worker`.
- Setiap `PUT /files` membawa `expected_sha256`. Tab tidak pernah berstatus "Tersimpan" sebelum `PUT` sukses.
- Teks UI hanya lewat i18n `workspace.*` (id dan en sama). Path, isi file, dan preview tampil sebagai teks.
- Batas: tree `depth=1` per permintaan; batas server dihormati (`meta.truncated`, `too_large`).
- Checks: `npm run format:check && npm run lint && npm run lint:guards && npm run typecheck && npm test`, `npx vite build`, `npm audit --omit=dev --audit-level=high`.

## Review Focus

1. **Konflik setelah "Timpa dengan versi saya":** konflik kedua (server berubah lagi) tampil lagi sebagai konflik, tidak pernah menimpa. Test dengan dua 409 berturut-turut.
2. **Tutup tab saat sedang menyimpan:** jawaban yang datang belakangan tidak menghidupkan tab lagi dan tidak menulis ulang sha tab lain. Test di reducer.
3. **File dihapus di server saat terbuka:** `PUT` → 404 → status "Gagal: file tidak ada lagi", tidak "Tersimpan".
4. **Nama file berisi spasi, `#`, `%`, atau Unicode:** URL path di-encode per segmen; test MSW memeriksa path yang diterima server.
5. **Repo kosong atau `repository_not_ready`:** pesan yang tepat, bukan layar kosong. Test per kode.
