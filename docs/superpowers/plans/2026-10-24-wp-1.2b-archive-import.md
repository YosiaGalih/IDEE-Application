# WP-1.2b (🔒) Safe archive import — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `import_archive(archive, dest)` extracts zip / tar / tar.gz into a new project folder, or rejects the whole archive and leaves nothing behind (FR-015, AC-02, SECURITY_MODEL T2/T4).

**Architecture:**
- Extraction goes into a fresh staging folder next to `dest`. Every entry is created through the WP-1.2a primitives (`split_rel`, `open_parent`, `O_CREAT|O_EXCL|O_NOFOLLOW`).
- Byte limits are counted on the **decompressed stream we read**, never on header claims.
- Success renames staging to `dest`. Any failure removes the staging folder.

**Tech Stack:** stdlib `zipfile`, `tarfile` (stream mode `r|`), `gzip`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-24-wp-1.2-workspace-git-design.md` (section 1.2b).

## Global Constraints

- **Limits** (ADR-005), via `ArchiveLimits` defaults:

  | Limit | Default |
  |---|---|
  | `max_archive_bytes` | 200 MiB |
  | `max_total_bytes` | 1 GiB |
  | `max_entries` | 50 000 |
  | `max_ratio` | 100 |
  | `ratio_floor_bytes` | 1 MiB |

  Both ratio checks apply only once the output under test exceeds `ratio_floor_bytes` [Menebak]. A tiny archive of repetitive text is not a bomb.
- **Rejection** is `ArchiveRejected(reason)` → 400 `ARCHIVE_REJECTED`, `details=[{"reason": reason}]`.

  `reason` ∈ {`format`, `oversize`, `too_many_files`, `ratio`, `traversal`, `absolute`, `link`, `device`, `duplicate`, `git_dir`, `invalid_name`}.
- `dest` must not exist; if it does → `AlreadyExists` (409). Its parent must exist.
- **Modes:** files 0644, or 0755 when the archive marks any exec bit; dirs 0755; never setuid/setgid. The final `dest` is 0755.
- **Strip prefix:** `strip_single_root` defaults to **False** (revised during implementation: stripping by default silently restructured a project whose only top-level entry is `src/`); `True` strips one wrapping top-level folder.

## Review Focus

1. **Archive with only directory entries / empty archive** → accepted, empty project (`files == 0`), no crash.
2. **Entry names with `./` prefix** (common in tar) are normalised, not rejected.
3. **A file later followed by `name/child`** (file-then-dir conflict) → `duplicate`, not a 500.
4. **Truncated / corrupt gzip** → `format`, staging removed.
5. **Encrypted zip entry** → `format`.

- [ ] **Step 3: Implement.**
  - **Format** is chosen from the magic bytes: `PK\x03\x04` / `PK\x05\x06` → zip; `\x1f\x8b` → gzip + tar stream; `ustar` at offset 257 → plain tar. Anything else → `format`.
  - **Zip:**
    - check `len(infolist()) > max_entries` and the declared sizes first;
    - stream `zf.open(info)` in 64 KiB chunks;
    - entry ratio = `file_size / max(compress_size, 1)`;
    - the file type comes from `external_attr >> 16`.
  - **Tar:** use `gzip.GzipFile` wrapped in a counting reader, then `tarfile.open(fileobj=…, mode="r|")`. The counting reader raises:
    - `oversize` past `max_total_bytes`;
    - `ratio` past `max_ratio * archive_size` (above the floor).

    This also caps memory for oversized pax headers at those bounds; the residual risk is noted in the tracker.
  - **Per entry:** `split_rel` (`absolute`/`traversal` kept, any other violation → `invalid_name`), then the `.git` segment check, then a kinds map `path → "file" | "dir"` for the duplicate and file-then-dir checks. A repeated dir entry is allowed.
  - **Write sequence:** files are written with `O_WRONLY|O_CREAT|O_EXCL|O_NOFOLLOW` under the staging fd.
  - **On failure:** any `zipfile.BadZipFile`, `tarfile.TarError`, `EOFError`, `zlib.error`, `OSError` from the decoders, or `RuntimeError` (encrypted) → `ArchiveRejected("format")`.
  - **On success:** strip-root is decided after extraction (staging holds exactly one dir and nothing else). Then `os.rename` to `dest`. In `finally`, `shutil.rmtree(staging, ignore_errors=False)` runs whenever staging still exists.
