# WP-1.1a Backend Core Skeleton Implementation Plan

> **For agentic workers:** Dieksekusi *Native* (`superpowers:executing-plans`) di sesi utama karena batas budget $207; review akhir oleh `kk-backend-reviewer` + `kk-security-reviewer`.

**Goal:** FastAPI app dengan config fail-start, envelope error, redaksi, log JSON, health live/ready, scaffold Alembic, dan CI.

**Architecture:** `backend/app/{core,api,services}`; route tipis → `services/health.py`; layer diuji import-linter (`api` → `services` → `core`).

**Tech Stack:** Python 3.12, uv, FastAPI, Pydantic v2 + pydantic-settings, SQLAlchemy 2 async + asyncpg, redis-py asyncio, httpx, structlog, Alembic; pytest, pytest-asyncio, respx, Ruff, Pyright, import-linter.

**Spec:** `docs/superpowers/specs/2026-10-24-wp-1.1a-backend-core-skeleton-design.md`

## Global Constraints

- `exclude-newer = 2026-10-10` (rilis ≥ 2 minggu); semua versi dipin di `uv.lock`.
- Envelope `{request_id, status, data, error, meta}`; `X-Request-ID` regex `^[A-Za-z0-9_-]{8,64}$`.
- Pesan error konfigurasi dan readiness **tidak pernah** memuat nilai variabel atau teks exception.
- Tidak ada `subprocess`/`requests`; SDK vendor tidak dipakai di slice ini.

## Review Focus

1. Nilai secret muncul di pesan `ConfigError`, misalnya lewat `ValidationError` pydantic yang menyertakan input.
2. Exception dependency (DSN berpassword) bocor ke respons `/health/ready` atau ke log.
3. Pola redaksi terlalu rakus (`token_count = 3`, `secret_santa`) atau terlalu longgar (`Authorization: Bearer …` huruf kecil).
4. `X-Request-ID` dari klien berisi karakter berbahaya dan memantul ke header/log.
5. Handler 500 membocorkan stack trace atau path absolut.
