# WP-3.1a Port LLM, adapter Anthropic, ScriptedProvider, tarif — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Satu port `LLMProvider` dengan adapter SDK Anthropic dan `ScriptedProvider`, retry yang melaporkan setiap percobaan, dan estimasi biaya dari tabel tarif berversi, tanpa key atau prompt di log.

**Architecture:** `app/llm/` adalah lapisan baru (llm → core). `base.py` berisi tipe data dan Protocol; `retry.py` membungkus provider mana pun; `anthropic_provider.py` satu-satunya pengimpor `anthropic`/`httpx2`; `scripted_provider.py` + `scenarios/` deterministik dan tanpa state; `pricing.py` membaca `backend/config/pricing.yaml`; `factory.py` memilih provider dari `Settings`. `CancelToken` di `app/core/cancel.py`.

**Tech Stack:** Python 3.12, `anthropic` 1.13.0 (`httpx2.MockTransport` untuk test), Pydantic 2, PyYAML, pytest + pytest-asyncio, import-linter, Pyright standard.

**Spec:** `docs/superpowers/specs/2026-11-05-wp-3.1-agentic-core-design.md` (bagian "3.1a — rancangan").

## Global Constraints

- Hanya `app/llm/anthropic_provider.py` yang mengimpor `anthropic` dan `httpx2`/`httpcore2` (CLAUDE.md #6, ADR-023).
- Library baru: rilis sebelum `exclude-newer = 2026-10-10`; `uv lock` lalu `uv sync --locked`.
- Retry: hanya `rate_limited`, `overloaded`, `transient`, `timeout`; maks 4 ulangan; backoff full jitter dasar 1 dtk, faktor 2, plafon 30 dtk; `retry-after` > 60 dtk → tidak diulang.
- Nama tool kanonik `^[a-z][a-z0-9_]*(\.[a-z][a-z0-9_]*)*$`, tanpa `__`, ≤ 64 setelah encode `.`→`__`.
- Biaya `Decimal` eksak (direvisi saat review: tanpa pembulatan, harga harus > 0, `partial` wajib); tarif tidak dikenal → `None` + `unavailable`, tidak pernah 0.
- Logger `anthropic`, `httpx2`, `httpcore2` minimal WARNING apa pun `LOG_LEVEL`-nya, plus filter di handler root (direvisi saat review: `httpx`/`httpcore` tidak diubah).
- Exception SDK tidak dirantai (`raise … from None`); pesan `LLMError` tanpa body request/response.
- Identifier Inggris, docstring/komentar Inggris (konvensi repo), dokumen Indonesia.

## Review Focus

1. **Error di tengah stream setelah delta terkirim** (`event: error` overloaded setelah teks) → `LLMError(overloaded)` dengan usage parsial, bukan respons setengah jadi. Test di Task 5.
2. **`ANTHROPIC_LOG=debug` di environment** menyetel level logger SDK saat import, setelah `configure_logging` berjalan. Test di Task 5 mengimpor adapter setelah konfigurasi.
3. **Model mengembalikan nama tool yang tidak ada di request** → di-decode dan diteruskan apa adanya; penolakan tugas ToolGateway (3.1d). Test di Task 5 memastikan adapter tidak menebak atau membuang.
4. **`retry-after` berbentuk tanggal HTTP atau tidak valid** → diabaikan (backoff biasa), bukan crash. Test di Task 5.
5. **Percobaan dibatalkan sebelum `message_start`** → usage `None`, `cost_status` `unavailable` (bukan `partial` 0 token). Test di Task 3 + Task 2.

### Task 3: Retry yang melaporkan setiap percobaan

**Files:**
- Create: `backend/app/llm/retry.py`
- Test: `backend/tests/unit/test_llm_retry.py`

**Interfaces:**
- Consumes: `LLMProvider`, `LLMRequest`, `LLMResponse`, `LLMError`, `Usage`, `CancelToken` (Task 1).
- Produces: `RetryPolicy(max_retries: int = 4, base_s: float = 1.0, factor: float = 2.0, cap_s: float = 30.0, max_retry_after_s: float = 60.0)`; `AttemptRecord(provider: str, model: str, attempt: int, request_id: str | None, usage: Usage | None, duration_ms: int, status: Literal["ok", "error", "cancelled"], error_kind: ErrorKind | None)`; `AttemptHandler = Callable[[AttemptRecord], Awaitable[None]]`; `async create_with_retry(provider, req, *, policy=RetryPolicy(), on_text_delta=None, cancel=None, on_attempt=None, sleep=asyncio.sleep, rng=random.random) -> LLMResponse`.

Jeda percobaan ke-n (n mulai 1) = `rng() * min(cap_s, base_s * factor ** (n - 1))`, lalu `max(jeda, retry_after_s)` bila ada. Jeda menunggu `sleep` dan `cancel.wait()` bersamaan; cancel menang → `LLMError("cancelled")`.

- [ ] **Step 1: Write failing tests** dengan provider palsu yang memutar daftar hasil:
  - `test_success_first_try_one_record`;
  - `test_retries_retryable_then_succeeds`: 2× `overloaded` lalu ok → 3 record, nomor 1..3, jeda `[rng*1, rng*2]`;
  - `test_gives_up_after_four_retries`: 5 percobaan, error terakhir diteruskan;
  - `test_non_retryable_not_retried` (parametrize `refusal`, `bad_request`, `auth`, `malformed`, `max_tokens`);
  - `test_retry_after_is_honoured`: `retry_after_s=7`, rng 0 → sleep 7;
  - `test_long_retry_after_is_not_waited`: 61 → error tanpa sleep;
  - `test_cancel_during_backoff`: cancel saat sleep → `LLMError("cancelled")`, tidak ada percobaan berikutnya, record terakhir `status="error"` untuk percobaan yang gagal;
  - `test_failed_attempt_reports_partial_usage`: error dengan `usage` → record membawa usage itu;
  - `test_cancelled_attempt_record`: provider melempar `cancelled` → record `status="cancelled"`.

- Produces:
  - `Reply(content: tuple[TextBlock | ToolUseBlock, ...], stop_reason: StopReason = "end_turn", usage: Usage = Usage(100, 20))`;
  - `Fail(kind: ErrorKind, retry_after_s: float | None = None, usage: Usage | None = None)`;
  - `Turn = Reply | Fail | Callable[[LLMRequest], Reply | Fail]`;
  - `Scenario(name: str, default: tuple[Turn, ...], scripts: Mapping[str, tuple[Turn, ...]] = {})`;
  - `SCENARIOS: Mapping[str, Scenario]` di `scenarios/__init__.py`;
  - `ScriptedProvider(scenarios=SCENARIOS, default_scenario="generic", delta_size=16)` dengan `name = "scripted"` dan `requests: list[LLMRequest]`.

Giliran = jumlah pesan `assistant` di `req.messages`. Naskah = `scripts[metadata["agent_id"]]` bila ada, selain itu `default`. Giliran melewati naskah → giliran terakhir diulang. Request ID `scripted-<scenario>-<turn>`.

Skenario:
- `generic`: giliran 0 = teks "Scripted response.", ditambah `ToolUseBlock` ke `submit_result` dengan input `{}` bila `submit_result` ada di `req.tools`;
- `faults`: dipilih per `agent_id` = nama jenis error (`"rate_limited"` → `Fail("rate_limited", retry_after_s=1)`, dst.), plus `"slow_stream"` (teks panjang untuk uji cancel).
