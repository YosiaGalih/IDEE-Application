## Found while executing

- tecnativa/docker-socket-proxy binds `:::2375` and dies on hosts without IPv6 → `DISABLE_IPV6=1`.
- The caddy binary carries a file capability, so it cannot exec as uid 101 under `cap_drop: ALL` + `no-new-privileges` → the placeholder web uses nginx-unprivileged (as DEPLOYMENT §2 intends for `web`).
- The API refuses to start in production as a superuser/owner (WP-1.1b audit guard) → runtime role split.
- `celery beat --schedule /tmp/beat/schedule` fails (folder missing) → `/tmp/celerybeat-schedule`.
- `read` with a tab IFS collapses an empty health column → `healthcheck.sh` uses `|`.
