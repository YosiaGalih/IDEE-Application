# WP-3.2c2a — integritas RunStore: rencana implementasi

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menutup jendela retry `start` dan pintu `fail` dengan token start per `_Run`, menyatukan tiga penutup baris `agent_runs` ke satu helper, memuat registry agent di worker, dan menyeragamkan tabel tarif. Semua ini dikerjakan sebelum `build_agent_runtime` punya pemanggil produksi (3.2c2c).

**Architecture:**
- `app/services/agent_run_rows.py` (baru): `close_run_row`, yaitu penutup baris tunggal.
- `app/agents/runtime.py` / `app/services/agent_runtime.py`: token start.
- Migrasi 0013.
- `app/worker/registry.py` (baru): `RegistryStep`.
- `SmokeEnv.pricing`: injeksi tarif.

**Tech Stack:** Python 3.12, SQLAlchemy async, Alembic, PostgreSQL 16, Celery 5 bootsteps.

**Spec:** `docs/superpowers/specs/2026-11-17-wp-3.2-workflow-engine-design.md` §16.3 (Keputusan #66–#71) dan §16.3a (builder check, #72). Jawaban §16.3a mengikat bila berbeda dari §16.3.

## Global Constraints

- **Import-linter tetap bersih:**
  - `app.services` tidak mengimpor `app.worker`;
  - `app.services.agent_run_rows` masuk kontrak "The runtime ends agent runs; it never moves a task" dan tidak mengimpor `app.models.tasks`;
  - `app.api`/`app.main` tidak pernah mengimpor modul itu, langsung maupun tidak langsung.
- **Satu-satunya UPDATE `agent_runs`** ada di `agent_run_rows.py`. Satu-satunya INSERT ada di `AgentRunWriter.start`.
- **`start_token`:**
  - tidak pernah masuk event, API, atau log (redactor menganggap kunci berakhiran `token` sebagai secret);
  - `RunStart.start_token` wajib, tanpa default;
  - `RunStore.fail(..., start_token)` adalah kwarg wajib.
- **Tidak ada perubahan perilaku pada penutup run.** Kolom dan payload event `finish`/`fail`/recovery sama persis dengan sebelumnya, kecuali clamp `INT4_MAX` yang kini seragam. `fail` tetap tanpa `duration_ms`.
- **Galat dicatat hanya dengan tipenya:** tidak ada `exc_info` dan tidak ada teks pesan di log baru.
- **Test:**
  - hanya lewat `/tmp/claude-0/-home-user-IDEE-Application/daa04f0b-5e7a-50f4-90ad-ee39ea239dff/scratchpad/p32-pytest.sh`, satu proses pytest dalam satu waktu;
  - fixture yang mirip secret dibangun dengan konkatenasi;
  - test infra memakai `python3 -m unittest discover -s infra/tests`.
- **Perintah dari `backend/`:** `uv run ruff check . && uv run ruff format --check . && uv run pyright && uv run lint-imports`. Sesudah autofix, jalankan ulang semuanya.

## Review Focus

1. **Jendela retry `start`.** Request ganda B dengan id sama meng-commit baris lebih dulu. Start ulang A harus menghasilkan `AgentRunIdConflict`, dan baris B tetap `running` tanpa `agent.run_finished`. Test di Task 2 (regresi probe AG-13).
2. **Pintu `fail`.** Bila kedua penutupan A gagal, `fail` A tidak boleh mengakhiri baris B (task dan agent sama, token beda). Test di Task 2.
3. **Refactor penutup tanpa perubahan perilaku.** Test karakterisasi ditulis lebih dulu, di Task 1, dan harus lulus sebelum dan sesudah refactor.
4. **Worker tidak start dengan registry rusak.** Test di Task 3.
