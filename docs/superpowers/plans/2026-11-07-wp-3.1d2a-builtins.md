## Global Constraints

- Layer: builtin di `app/tools/builtin/` hanya memakai `app.workspace`, `app.gitops`, `app.core`, `app.tools`, dan `app.llm.base`; tidak ada `app.services`/`app.agents`/`app.workflow`.
- Setiap path yang dikembalikan ke model lolos `Policy.denied(..., AGENT_READ)` dengan policy gabungan `repo/` + worktree.
- Setiap keluaran builtin lewat pembungkus gateway; tidak ada isi mentah repo di `content`.
- Tidak ada subprocess di luar `app/gitops/`.
- Setiap langkah: test merah dulu, lalu hijau; ruff, format, pyright 0 error, lint-imports.
