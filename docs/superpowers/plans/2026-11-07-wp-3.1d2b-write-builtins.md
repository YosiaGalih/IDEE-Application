# Plan WP-3.1d2b — builtin yang menulis (`code.*`, `git.commit_task`) dan `repo.search_symbol`

Spec: `docs/superpowers/specs/2026-11-07-wp-3.1d-tool-gateway-design.md` (Goals 3.1d2b, Keputusan Lead 3.1d2b). Branch: dari `main` sesudah PR 3.1d2a. Satu PR. 🔒 (menulis worktree, commit git, port DB).

## Global Constraints

- Layer: builtin hanya memakai `app.workspace`, `app.gitops`, `app.core`, `app.tools`; data DB hanya lewat `ToolPorts` (ADR-022). Implementasi port di `app/services/`.
- Tool R1 = `side_effect=True` dan `write_paths` untuk tool yang menulis berkas (gateway menolak pendaftaran tanpa itu).
- Tidak ada isi berkas di pesan `ToolError`; hanya path yang diberikan model, nomor hunk, dan kode alasan.
- Tidak ada subprocess di luar `app/gitops/`.
- Setiap langkah: test merah dulu, lalu hijau; ruff, format, pyright 0 error, lint-imports. Test DB hanya di `kodekantor_test_wt2` (Redis 9), satu run pada satu waktu.
