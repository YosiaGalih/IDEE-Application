# WP-3.2c2c2: wiring runtime (rencana implementasi)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Engine memanggil `AgentRuntime` untuk pertama kalinya, lewat langkah, tanpa langkah produksi terdaftar (N27). Yang dikerjakan:
- pemetaan hasil run → `StepResult`/`StepAbandoned`/`LeaseLost` yang murni dan total, dengan himpunan `tasks.error_code` tertutup;
- adapter `AgentStep` dengan urutan tangkap tetap, id run baru per `run()`, pemeriksaan `AgentProfile`, dan kalimat tetap;
- `build_orchestrator` merakit `build_agent_runtime` dengan owner lease delivery yang sama (C2);
- `execute_task` menyuntik registry dan tarif sebelum claim, lalu menunggu task yang terlepas sebelum `dispose` (N54);
- engine me-log hasil yang dibuang cancel luar di wait pertama;
- bukti end-to-end dengan `ScriptedProvider` atas tabel #8, termasuk regresi N53 dengan runtime asli;
- guard penulis status dikeraskan (hanya test).
