## Global Constraints

- Layer: `app.tools` → `app.workspace|gitops|sandbox`, `app.core`, `app.models`, dan dari `app.llm` hanya `app.llm.base`. Tidak ada `app.services`/`app.workflow`/`app.agents` di tools (ADR-022: lewat `ToolPorts`).
- Status task hanya lewat `workflow.states.transition`; status approval hanya lewat `approval_store`.
- Tidak ada secret/input mentah di log, audit, event, `tool_calls`, atau `content` ke model.
- Setiap langkah: test merah dulu, lalu hijau; ruff, format, pyright 0 error, lint-imports.
- Migrasi 0008 lulus `upgrade head → downgrade -1 → upgrade head`.
