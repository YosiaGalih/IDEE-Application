## Yang dibangun

1. **`app/core/rbac.py`** (logika murni, tanpa DB):
   - matriks role → permission persis API_CONTRACTS §2;
   - permission khusus global (`admin:users`, `admin:policies`, `settings:providers`, `audit:read`, `usage:read_all`) hanya dari grant `global`;
   - grant `global` berlaku di project milik user dan project tempat dia diberi role; grant `project:<id>` hanya di project itu;
   - pemilik project selalu `owner` di project-nya.
2. **`app/core/security.py`**: hash dan verifikasi password argon2id; token acak + sha256 untuk sesi dan reset (yang disimpan hanya hash).
3. **Model dan migrasi `0002_identity`**: `users` (email unik lower-case), `user_roles` (unique `(user_id, scope)`, CHECK role), `sessions` (token_hash unik), `password_reset_tokens`. Seluruh FK `ON DELETE CASCADE` sesuai DATA_MODEL.
4. **`python -m app.cli create-owner --email … --display-name …`**:
   - password dibaca dari prompt (`getpass`) atau stdin, tidak pernah dari argumen;
   - menolak bila owner sudah ada;
   - mencatat audit `user.owner_created`.

## Di luar scope (WP-1.1d 🔒)

Endpoint `/auth/*`, cookie sesi + CSRF double-submit, rate limit dan lockout, reset password.
