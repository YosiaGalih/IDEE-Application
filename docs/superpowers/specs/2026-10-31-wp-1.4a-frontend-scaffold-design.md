## Intent

Frontend belum ada di repo; `web` di compose masih placeholder nginx. WP-1.4a membangun fondasi yang dipakai semua layar sesudahnya, sehingga WP-1.4b dan seterusnya hanya menulis fitur:
- proyek Vite + React 19 + TypeScript strict;
- lint yang menegakkan aturan kontrak;
- token desain dan UI kit;
- klien API yang memahami envelope, CSRF, dan idempotensi;
- stream SSE yang bisa dilanjutkan;
- i18n id/en;
- image `web` yang sesungguhnya;
- CI.

**Goals**
1. `frontend/` lulus `npm run lint`, `typecheck`, `test`, `build`, `format:check`, dan semuanya berjalan di job CI `frontend`.
2. **Klien API** (`src/api/`):
   - setiap respons divalidasi Zod;
   - error envelope menjadi `ApiError` bertipe;
   - `X-CSRF-Token` dibaca ulang dari cookie di setiap mutasi;
   - `Idempotency-Key` dikirim di setiap mutasi;
   - setiap error dipetakan ke salah satu state UX wajib.
3. **SSE** (`src/api/sse/`):
   - melanjutkan dari `seq` terakhir setelah putus;
   - membuang event yang sudah diterima (dedupe `seq`);
   - mendeteksi stream yang diam (heartbeat `: ping` 15 dtk);
   - melaporkan status `connecting/open/reconnecting/disconnected`.
4. **i18n:** `id` (default) dan `en` dengan kunci yang sama persis. Teks literal di JSX ditolak lint.
5. **Image `kodekantor/web`:**
   - dibangun dari `frontend/` menggantikan placeholder;
   - nginx-unprivileged, `/healthz`, fallback SPA, `/assets/*` immutable, `index.html` no-cache;
   - lolos `clean-install` dan Trivy.
6. **`security-scan`:** ditambah `npm audit --omit=dev` serta Semgrep `p/typescript` dan `p/react` (SECURITY_MODEL §11).

**Anti-goals**
- `dangerouslySetInnerHTML` di mana pun.
- Token atau secret di `localStorage` atau variabel `VITE_*`.
- CDN pihak ketiga (CSP `default-src 'self'`).
- Teks UI hard-coded.
- Status yang hanya dibedakan lewat warna.

## State UX

Kontrak (frontend.md, PRD §4.1–§4.2) mewajibkan 11 state. `src/api/uxState.ts` memetakan `ApiError` ke salah satunya:

| State | Pemicu |
|---|---|
| `permission_denied` | 403 `FORBIDDEN` / `POLICY_DENIED` |
| `capability_disabled` | 403 `CAPABILITY_DISABLED` |
| `unauthenticated` | 401 |
| `quota_exceeded` | 429 `QUOTA_EXCEEDED` |
| `rate_limited` | 429 `RATE_LIMITED` |
| `provider_degraded` | 503 |
| `timeout` | AbortSignal timeout |
| `disconnected` | kegagalan jaringan, atau status SSE `disconnected` |
| `not_found` | 404 |
| `error` | selain di atas |

`StateView` menampilkan setiap state dengan ikon, teks, dan aksi (coba lagi, masuk). Dua state ditangani di luar pemetaan error: `empty` dan `loading` adalah state data, dan `partial_success` disediakan sebagai varian.

## Testing

Semua test di `frontend/src/**/__tests__/` (TEST_STRATEGY), dengan Vitest + RTL + jsdom; MSW untuk HTTP.

| Bagian | Yang diuji |
|---|---|
| Klien API | envelope sukses/gagal; respons non-JSON; skema data salah; CSRF dibaca ulang setelah cookie berganti; mutasi tanpa cookie ditolak sebelum fetch; `Idempotency-Key` ada di mutasi tetapi tidak di `/auth/*` dan GET; timeout; pemetaan `uxState` untuk semua kode |
| Parser SSE | `id`/`event`/`data` multi-baris; komentar; CRLF; potongan chunk di tengah baris |
| `eventStream` | resume dengan `after_seq` + `Last-Event-ID`; dedupe; event efemeral tanpa id; backoff; heartbeat diam → reconnect; abort; status. Nama file `useTaskEvents.test.ts` mengikuti TEST_STRATEGY. |
| i18n | `id` dan `en` punya set kunci yang sama |
| UI | `StateView` merender setiap state dengan teks + ikon; `StatusPill` |
| Shell | route dikenal merender layout; route tak dikenal → 404 |
| Lint | `no-restricted-imports` antar fitur, `new WebSocket`, dan teks literal diuji lewat fixture yang harus gagal lint |
