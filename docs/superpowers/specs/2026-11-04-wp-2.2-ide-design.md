## 2.2a — rancangan

### Intent

User membuka project dan bekerja dengan file-nya seperti di editor biasa: menelusuri folder, membuka beberapa file dalam tab, mengedit, lalu menyimpan. Penyimpanan tidak pernah menimpa perubahan orang lain diam-diam; konflik selalu tampil dan user yang memutuskan. Panel kanan dan bawah sudah memberi tempat untuk chat dan terminal, tetapi jujur menyatakan bahwa keduanya belum tersedia.

### Goals

1. **Route `/projects/:projectId/workspace`** menggantikan placeholder. Layar dimuat secara lazy (`React.lazy`), sehingga Monaco tidak membebani dashboard dan layar lain.
2. **Layout (FR-026):**
   - Header: nama project, branch (`repository.branch`), dan tautan kembali ke daftar project.
   - Kiri: explorer.
   - Tengah: tab editor.
   - Kanan: panel bertab **Cari** dan **Chat**. Chat berstatus `capability_disabled`, dengan keterangan bahwa chat datang bersama alur task.
   - Bawah: panel **Terminal** dan **Tests**, berstatus `capability_disabled` dengan alasannya. Panel bisa disembunyikan atau ditampilkan.
3. **Explorer:**
   - `GET /tree?path=.&depth=1` saat dibuka; folder diperluas dengan `GET /tree?path=<folder>&depth=1` saat diklik (lazy).
   - Urutan: folder dulu, lalu nama. Ukuran file tampil seperti di mockup.
   - `meta.truncated` → baris "isi folder terpotong".
   - Badge status git dari `GET /git/status` (A/M/D/R/?, teks + ikon, bukan warna saja). Bila git status gagal, explorer tetap jalan dan badge tidak tampil, dengan keterangan.
   - Aksi bila user punya `workspace:write`:
     - file baru dan folder baru (`POST /files`);
     - hapus file (`DELETE /files/{path}?expected_sha256=`) dengan konfirmasi, memakai sha versi yang dibuka atau dibaca ulang.
   - Rename dan pindah tidak ada di kontrak, jadi tidak dibuat.
4. **Editor (FR-027):**
   - `monaco-editor` (ESM, dibundel lokal; worker lewat `?worker` Vite, sesuai CSP). Tanpa `@monaco-editor/react`, karena loader-nya memakai CDN.
   - Komponen tipis `CodeEditor` membungkus `monaco.editor.create`. Test Vitest mengganti komponen ini dengan stub, karena jsdom tidak bisa menjalankan Monaco.
   - Multi-tab: membuka file yang sudah terbuka hanya mengaktifkan tab-nya; tab bisa ditutup.
   - Bahasa dari field `language` respons file, dipetakan ke id Monaco; bila tidak dikenal → `plaintext`.
   - Opsi Monaco: `links: false`, sehingga URL di isi repo tidak bisa dibuka dengan klik (isi repo tidak tepercaya; frontend.md); `readOnly` bila user tidak punya `workspace:write`.
5. **File biner atau besar (FR-032):** `content: null` dengan `encoding: "binary"` atau `too_large: true` → tab berisi metadata (path, ukuran, sha256, alasannya), tidak dimuat ke editor.
6. **Simpan (FR-029, FR-030):**
   - Ctrl/⌘+S dan tombol Simpan → `PUT /files/{path}` `{content, expected_sha256: <sha versi yang dibuka>}`.
   - Status per tab, berupa teks + ikon: **Tersimpan**, **Belum disimpan**, **Menyimpan…**, **Gagal** (dengan alasan dan tombol coba lagi), **Konflik**.
   - Sukses → sha versi yang dibuka diganti dengan sha baru.
   - 409 `VERSION_CONFLICT` → dialog konflik dengan tiga pilihan:
     - **Lihat perbedaan:** Monaco diff editor antara versi server (dibaca ulang) dan versi user.
     - **Muat versi server:** perubahan user dibuang, setelah konfirmasi.
     - **Timpa dengan versi saya:** `PUT` dengan sha versi server yang baru dibaca. Ini pilihan sadar, tidak pernah otomatis.
   - Tutup tab atau pindah halaman dengan perubahan belum disimpan → konfirmasi (dialog, plus `beforeunload`).
7. **Panel Cari (FR-020/021):**
   - Mode teks (literal atau regex, abaikan kapital) dan simbol (filter kind), plus glob.
   - Hasil `{path, line, preview}` tampil sebagai teks; klik membuka file dan menaruh kursor di baris itu.
   - `meta.truncated` dan `meta.skipped` ditampilkan.
   - Error 422 `regex_unsupported`, 409 timeout, dan 429 tampil dengan teks masing-masing.
   - Untuk mode simbol: `meta.index_truncated` dan `indexed_at` ditampilkan; "belum diindeks" bila `indexed_at` null.
8. **Izin:** tombol tulis dan mode edit hanya untuk `permissions` yang memuat `workspace:write` (dari `GET /projects/{id}`). Server tetap menjadi penentu: 403 dari server tampil sebagai `permission_denied`.
9. **State wajib:**
   - loading (skeleton tree, spinner file);
   - error, timeout, disconnected (`StateView` + coba lagi);
   - not found (project di luar scope → 404 → `not_found`);
   - empty (repo kosong; tidak ada hasil cari);
   - `repository_not_ready` dan `repository_missing` → pesan dari backend, dengan tautan import bila sesuai.
10. **i18n:** semua teks lewat `workspace.*` (id dan en). Isi file, path, dan preview pencarian adalah data, bukan teks UI.

### Non-goals

- Chat, terminal, dan tests run: lihat pembagian.
- Panel git (commit, diff, branch): 2.2b.
- Patch preview untuk patch agent (FR-031): bersama alur task.
- Rename atau pindah file, upload file lewat explorer, dan editor kolaboratif.
- Autosave: simpan selalu eksplisit [keputusan Lead], karena autosave dengan cek versi menghasilkan konflik yang membingungkan.

### Anti-goals

- Penyimpanan yang menang-terakhir: setiap `PUT` membawa `expected_sha256`.
- Monaco atau worker dari CDN.
- Tautan dari isi repo yang bisa diklik.
- Tab yang tampil "Tersimpan" padahal `PUT` gagal.

### Approaches

1. **Monaco ESM langsung dengan wrapper tipis (dipilih).** Dibundel lokal, worker same-origin, dan kontrol penuh atas opsi keamanan (`links`).
2. **`@monaco-editor/react`.** Ditolak: loader default memuat Monaco dari CDN, dan mengubahnya ke lokal menambah lapisan tanpa manfaat.
3. **CodeMirror 6.** Ditolak: kontrak dan rules menetapkan Monaco.

### Keputusan Lead (dicatat; konflik #71)

- Chat (FR-033–040) pindah ke WP-3.2 dan terminal (FR-077–083) ke WP-4.1, karena backend-nya belum ada.
- Panel git menjadi 2.2b.
- Simpan eksplisit, tanpa autosave.
- Konflik diselesaikan lewat dialog tiga pilihan, dan menimpa selalu memakai sha server yang baru dibaca.
- `links: false` di Monaco.

### Test

- `frontend/src/features/workspace/__tests__/`. MSW untuk API; `CodeEditor` di-stub dengan textarea.
  - explorer: lazy load, truncated, badge git, git status gagal;
  - buka file, multi-tab;
  - simpan sukses, simpan 409 (ketiga pilihan), simpan gagal;
  - tutup tab dengan perubahan belum disimpan;
  - file biner/besar;
  - readonly tanpa `workspace:write`;
  - panel cari (hasil, regex 422, 429, truncated);
  - state 404/timeout/disconnected;
  - konten berbahaya (nama file, preview) tampil sebagai teks.
- `src/api/__tests__/workspace.test.ts`: Zod untuk tree, file, git status, dan search; error 409 membawa sha server.
- Playwright (live check, karena e2e belum di-scaffold):
  - Monaco nyata termuat tanpa error CSP di image `web` (Caddy + CSP dari `infra/caddy/Caddyfile`), atau di Vite dev bila stack tidak bisa dijalankan;
  - edit lalu simpan;
  - konflik dari dua tab browser.

### Yang diserahkan ke builder

- Tata letak dan ukuran panel (boleh tanpa resize di 2.2a).
- Pemetaan `language` → id Monaco.
- Struktur komponen di `features/workspace/`, asalkan `CodeEditor` adalah satu-satunya tempat yang mengimpor `monaco-editor`.
